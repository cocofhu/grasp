# IDE logo sources

Marks for the sandbox info panel's local IDE menu. They are bundled locally so
the panel makes no runtime requests to an image host. The names and marks are
trademarks of their owners and are used only to link to the products.

- `vscode.svg` is the unmodified stable icon from Microsoft's
  [Visual Studio Code icons package](https://code.visualstudio.com/assets/branding/visual-studio-code-icons.zip)
  (version 2021-06-21). Usage follows the
  [Visual Studio Code brand guidelines](https://code.visualstudio.com/brand).
- `cursor.svg` and `jetbrains.svg` come from Simple Icons v16
  (`cdn.jsdelivr.net/npm/simple-icons@v16/icons/<slug>.svg`); `cursor.svg` is the
  same file as `../provider-logos/cursor.svg`. They are single-color marks and
  are drawn in the current text color.
- `codebuddy.svg` and `trae.svg` are the unmodified `codebuddy-color.svg` and
  `trae-color.svg` from [Lobe Icons](https://github.com/lobehub/lobe-icons)
  (`@lobehub/icons-static-svg@1.106.0`); the MIT notice is in
  [`../provider-logos/LICENSE.lobe-icons`](../provider-logos/LICENSE.lobe-icons).
