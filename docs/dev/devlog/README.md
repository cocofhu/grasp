# 开发日志

仓库内部流水，不发布到公开站点。不回填 git 历史，不写排期。

每条记录一个文件，按月份分目录：`docs/dev/devlog/YYYY-MM/YYYY-MM-DD-<slug>.md`。新增记录只新建自己的文件，不改别人的文件，并行的 PR 不会在日志上冲突。

- 日期：写下这条的当天（不是排期），同时决定月份目录。
- `<slug>`：几个英文小写单词，用 `-` 连接，概括这次改动，例如 `2026-11-02-i18n-console-warnings.md`。同一天内不要重名。
- 拆分前的历史记录用当天的序号命名（`2026-10-31-01.md` 最早），新记录不要再用序号。
- 按时间浏览：`ls docs/dev/devlog/*/` 按文件名排序即按日期排序；最新的在最后。

对外行为变化仍按原有惯例另记仓库根目录 `CHANGELOG.md` 的 `Unreleased`。没有对外行为时不要改 `CHANGELOG.md`。

## 条目模板

复制下面这一块，作为新文件的全部内容：

```text
# YYYY-MM-DD（一句话标题）

- 日期：YYYY-MM-DD（写下这条的当天，不是排期）
- 范围：路径
- 做了什么：
- 为什么：
- 如何验证：
```
