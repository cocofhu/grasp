# 2026-11-09 记录新安装数据库的实际来源

- 日期：2026-11-09
- 范围：数据库运行入口、新安装执行初始化及 `fresh_origin*.go`。
- 做了什么：只有建表前确认 SQL 不含应用表的入口，才能以当前连接内的私有证明保存独立的新安装来源记录；已有 schema、业务行或不同连接不能事后补写。

- 如何验证：数据库与维护命令的新安装、重启、业务数据增长、错误连接、零证明及半成品 schema 用例通过 race 三次、vet、lint；原离线升级收据协议保持独立。
