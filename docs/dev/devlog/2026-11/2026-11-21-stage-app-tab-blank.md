# 2026-11-21（资源面板恢复「应用」页签时空白）

- 日期：2026-11-21
- 范围：`web/src/components/run/ReactArtifactStage.vue`、`web/src/components/run/ReactArtifactStage.sandbox.test.ts`、`CHANGELOG.md`
- 做了什么：分栏资源面板切回上次的视图时，如果上次停在「应用」页签但当前没有已注册的预览，就回到资源主页，不再把当前页签设成看不见的「应用」。
- 为什么：`syncDrawerMode` 不检查 `showAppCard`，直接把当前页签设为 `novnc`。沙箱暂停时预览端口为空，「应用」页签头和内容都被隐藏，右侧只剩一个「+」，也看不到暂停提示和恢复按钮。预览类型一直是 `off`，原来那个「预览消失就回主页」的监听不会触发。沙箱正常运行时，切换会话后预览列表加载完之前也会短暂空白。
- 如何验证：新增单测：分栏资源模式、记住的页签为「应用」、没有预览端口时，显示资源主页且没有「应用」卡片，打开终端能看到暂停提示。去掉修复后该单测失败。前端 lint、类型检查、单测和构建通过。
