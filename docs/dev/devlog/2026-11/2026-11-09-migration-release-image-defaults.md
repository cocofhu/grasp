# 2026-11-09 配套迁移版的默认发布镜像

- 日期：2026-11-09
- 范围：`.env.example`、`start.sh`、`compose.release.yaml`。
- 做了什么：首次安装的服务、网关和环境镜像默认版本统一为 3.3.0，使用该迁移版新增的显式离线执行初始化命令。已有 `.env` 的显式镜像选择继续生效，版本发布前的验收使用已构建镜像的不可变摘要。
- 为什么：保留 3.2.0 默认镜像会让新安装文档要求的初始化命令在旧镜像中不存在。服务、网关和沙箱环境需要选择配套版本，旧数据仍须走独立升级流程。
- 如何验证：检查三处默认镜像版本一致，并使用 Compose 配置解析、现有初始化回归和真实摘要镜像 smoke 验证；后两项结果以最终验收记录为准，版本默认值变更本身不表示镜像已发布。
