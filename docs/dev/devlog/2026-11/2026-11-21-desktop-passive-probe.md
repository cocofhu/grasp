# 2026-11-21 云桌面连接与接管复核

首次打开预览会执行 CDP 就绪探测。Chromium 的 HTTP 开页接口会激活浏览器，即使探测随即关掉标签，Openbox 的焦点仍留在 Chromium。服务端和沙箱启动脚本改用 CDP 隐藏目标，目标随探测连接关闭而释放。

接管时重新读取桌面回合状态。全屏时确认框跟随预览面板，切换连接会清掉上一个桌面的确认请求。

用 Xvfb、Openbox、有窗口的 Chromium 和独立的编辑器窗口检查了焦点、几何尺寸与标签列表。服务端探测和启动脚本探测各重复三次。Playwright 覆盖全屏下取消与确认，组件测试覆盖缓存空闲后 Agent 开始运行和切换沙箱。
