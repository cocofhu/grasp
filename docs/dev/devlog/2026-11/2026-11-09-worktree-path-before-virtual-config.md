# 2026-11-09 本地工作区路径优先于工具配置映射

- 日期：2026-11-09
- 范围：`server/internal/sandbox/worktree_create.go`、工作树路径回归、`CHANGELOG.md`。
- 做了什么：本地文件操作先识别当前真实工作区，再映射虚拟工具配置目录；切换 Agent 配置目录时，原工作文件与选中的恢复副本保持原位置，配置文件仍进入当前私有目录。
- 为什么：工作区实际位于 `/root/.codex` 等虚拟配置前缀下时，原映射会把脏文件写入工具配置临时目录，切换后文件不可见。更换测试临时目录只能避开触发条件，不能解决真实路径重叠。
- 如何验证：通过真实文件读写覆盖二进制保留、配置目录切换、认证文件映射及当前恢复副本；在重叠的临时根下重复原工作树 Reprime 回归，并验证不重叠路径的完整 sandbox 测试。
