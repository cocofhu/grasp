# 2026-11-09 离线转换旧 Solo 历史与版本升级

- 日期：2026-11-09
- 范围：`server/cmd/storage-admin/upgrade*.go`、`server/internal/historymigration/`、数据库离线升级与 filestore 迁移、Solo 历史读取及升级文档。
- 做了什么：增加显式停写升级命令，先保留原 SQL 快照，再规范化正文、按原消息来源导入旧 Events，验证完整引用并保存不可变完成收据；同原维护目录的执行初始化重核转换结果。公共历史读取使用导入后的规范日志，保留原 Events 字节、可能截断提示和未知执行来源。修复 SQLite 旧 BLOB 原值条件更新的类型差异。
