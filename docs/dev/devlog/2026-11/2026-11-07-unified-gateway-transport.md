# 2026-11-07（Grasp 统一沙箱网关连接）

- 日期：2026-11-07
- 范围：`server/internal/{sandbox,config,runtime,services}`、`server/cmd/server`、`sandbox-gateway/gateway`、沙箱详情页、中英文网关文档与配置示例。
- 做了什么：
  - 保留默认 v1 直连，新增必需 API key 的 v2 信息发现和 `grasp-tcp-v1` WebSocket TCP 通道。网关按所属沙箱和声明端口解析当前驱动地址，不接受任意目标地址。
  - Grasp 通过共享的本地适配器复用原有 SSH、文件、终端、ACP/历史、IDE、CDP/noVNC 与预览协议；保留双方 EOF、二进制数据、长连接心跳和关闭清理。
  - 命名连接与默认连接分离；沙箱 ID 和创建标签保存网关绑定，重启或改变默认值不改写存量沙箱。环境 profile 在各网关映射镜像，Agent 工具选择仍独立；发现接口明确区分冷停止/内存暂停以及磁盘语义。
  - 网关通道自动启用独立预览来源；重启后重新解析 ACP、IDE 和预览端口，不回退缓存的本地端口。信息发现的 404 单独归类，不能判定沙箱已销毁。详情页将本地地址标为服务端端点，保留原有 Grasp 入口。
  - 补齐配置、升级顺序、回连要求、存量绑定和回退限制的说明；未改变镜像/运行时包发布契约或内网部署流水线。
- 为什么：E2B 的私有端点属于网关网络空间，原直连方案要求 Grasp 同机；统一认证通道使 Docker、Kubernetes 和 E2B 网关可以独立部署，同时保留业务协议与存量工作区。
- 如何验证：
  - Server/Gateway 的全量 Go 测试、golangci-lint、go vet、配置文档一致性检查；Server core 覆盖率 90.7%，Gateway 91.1%。新增网关绑定、移除连接、发现失败、缓存端口、TCP 半关闭、SSH 输出/退出码、HTTP/WS 大数据和 CDP 地址解析回归；通道及服务回归连续 20 轮 `-race`。
  - 前端 lint、vue-tsc、构建与 6,363 项单测通过，Lines 覆盖率 91.79%；CI 浏览器集 367 项全部通过，无失败、跳过或 flaky。
  - Agent 全量免费 E2E 84 个场景通过，覆盖 56 种有序工具互切、模型/推理强度切换、MCP/历史和文件保留；可配置 CLI 为真实进程，Cursor、Trae、Kimi Code 仍按原有矩阵标注平台协议 fixture，不声称厂商原生推理验证；付费调用为 0。
  - always-on 脚本检查、离线文档发布回归、文档构建与高/严重漏洞审计通过。测试记录保存在工作区外。三类后端覆盖的是驱动/协议回归，本次未升级内网网关，也未执行真实 E2B 部署联调。
