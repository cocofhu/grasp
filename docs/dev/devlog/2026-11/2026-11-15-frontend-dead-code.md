# 清理前端生产不可达的函数、文案键、API 方法与仓库垃圾文件

- **日期**：2026-11-15
- **范围**：`web/src/`、`web/public/`、`web/TimelineHarness.vue`、`web/coverage-auto-{final-,}lcov/`、`.gitignore`。
- **做了什么**：
  - 删除生产代码零调用、只剩自身单测在用的导出函数（约 60 个），连同因此失去调用方的内部常量、类型与 import：`clarifyDraftStash.{budgetImages,ackClarifyOutboxText}`、`theme.applyPublicLightChrome`、`firstInstall.{openFirstInstall,closeOnboarding}`、`nodeRegistry.{agentOutputDefs,PALETTE_GROUPS}`、`onboardingWizard` 4 个、`soloPrefs.repoProtocol`、`embedChat` 的 4 个路径构造与 2 个宿主消息解析、`gateShareLink.shareStatusLabel`、`reactArtifactPreview` 4 个、`useDialogue`、`sumTotalTokens`、`usePaletteGroups`、`backendAuthGuide.{authGuideFor,hasAuthKeyConfigured}` 及 8 份认证指引表、`chartTheme.TREND_CHART_GRID`（`pieLegend` 仍被内部使用，改为非导出）、`isValidRunIdShape`、`setAgentProfile`、`inboxDisplay` 4 个、`branchOfRepo`、`hasAutoAttempted`、`loadingRequest.{terminalFromCatch,createGenerationGate}`、`resolveTerminalState`、`credentialKinds.backendKind`、`tokenHubVariants`、`envConfiguredCount`、`pickAcpRails`、`runningAutoNode`、`snapshotHasContent`、`summarizeLlmTranscript`。对应单测只删涉及这些函数的断言；同一用例里覆盖保留函数的断言保留（如 `useNodeDefs`、`statsLegend`、`agentConfigRelPath`、dialogue 版本去重）。
  - 删除 12 个无调用方的 API 客户端方法（`packRunArtifactsUrl`、`getPmThread`、`appendPmMessage`、`patchPmMessage`、`ensurePmSandbox`、`getGateShareLink`、`getReviewShareLink`、`getSoloEnv`、`listWorkflowCatalog`、`getModelConfiguration`、`deleteModelConnection`、`deleteCredential`——后者与 `removeCredential` 重复），以及随之无人引用的 `WorkflowCatalogItem` / `SoloEnvEntry` / `SoloEnvSource` 类型和测试中的对应 mock。服务端接口不动。
  - 删除 867 个生产代码与 e2e 预览页都不引用的 i18n 键（中英同步；判定时把字面量、`tm()` 子树前缀、模板字符串 / 字符串拼接的动态前缀都算作引用），`lang.json` 因此清空，连同 `loadLocaleMessages` 中的两个 import 一起删除；`openCodeCopy.test.ts` 所锁定的 `agentStudio.openCode` 整组文案已无界面使用，一并删除。依赖已删键的文案测试断言同步删除，`TokenAnalyticsView` 测试改为对照界面实际使用的 `pages.board.tokenStats.pm`。
  - 去掉 `.vue` / `.ts` 中未使用的 import 与局部变量（`AppSidebarNav` 中只取不用的 `useBreakpoint()`、`SidebarWorkspaceLists.endedBadly`、`TokenDrillDownModal.currency` 等），`runStats` 两处未用参数和 `mergeAcpEvents.test` 一处未用变量，`npm run lint` 由 3 个 warning 变为 0。6 个只在本模块使用的类型去掉 `export`（`RegionOption`、`RegionPolicy`、`FilesStep`、`FilesOpenSnapshot`、`ActionIconName`、`ActionVariant`）。
  - 删除未被引用的 `web/TimelineHarness.vue`、误提交的 `web/coverage-auto-{final-,}lcov/` 报告资源、打包进 `dist` 但无入口的 `public/demos/clarify-busy-status.html`（修复前后对比 Demo）；`.gitignore` 增加 `web/coverage-*/`。
- **为什么**：这些代码在生产路径上永远不会执行，却要随功能演进持续维护、还会误导阅读者以为对应行为存在（例如嵌入页发出的 image/demo 消息宿主侧并无处理）。删除未被调用的函数与未被渲染的文案不改变任何运行时行为。
- **保留**：沿用 2026-11-13 的口径，测试种子与重置钩子（`reset...ForTest`、`flushMermaidQueue`、`createMemoryDraftIdb`、`clearBootRecords`、`markdown` 计数器、`unchangedIdsKeepIdentity`、`iconNames` 等）、`src/data/shellNavPaths.ts` 不动；`lib/icons/runtime.ts` 是 `build-live-overlay.mjs` 打包给沙箱的库入口，`hydrateRuntimeIcons` 保留；`clarifyInboxStage` 的 3 个函数和 `useRunTerminalNotifications.{mapRunToNotification,isBeforeBaseline}` 仍被 CI 关键 e2e 预览页使用，保留。
- **如何验证**：`npm run lint`（0 error 0 warning）、`vue-tsc --noEmit`、`npm test -- --coverage`（576 文件 / 6258 用例，行覆盖 91.74%）、`npm run build` 通过；`vue-tsc --noUnusedLocals` 对改动文件无新增告警；knip 复查无新增未用导出；文案审计脚本复跑 0 未用键；Playwright desktop 全量 519 例中 499 通过，其余 20 例在未改动的 HEAD 上以同样用例失败（noVNC、布局尺寸等既有问题），无新增失败。
