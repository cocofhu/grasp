# 2026-11-09（远端启动仅接受已收尾的存储认证）

- 日期：2026-11-09
- 范围：`server/internal/payloadstore/closure.go` 及相关测试
- 做了什么：纯 SQL 的远端主存储启动检查要求闭包收据有有效的 `FinalizedAt`。严格空来源首次绑定在同一事务完成位置与收据，因此完成、收尾时间相同。离线认证尚未显式收尾时，不能提前作为启动资格。
- 为什么：启动资格应直接表达认证已经完成全部步骤，不额外依赖其他维护屏障阻止未收尾操作启动。原操作的显式收尾和丢失回复核对语义保持不变。
- 如何验证：定向回归覆盖未收尾拒绝、收尾后放行、空首次绑定的原子收尾、只读检查与原收据恢复；相关包 race、vet、lint 随独立交付快照记录。
