# 2026-11-09 代码导入批量校验与显式根目录

- 日期：2026-11-09
- 范围：`sandbox-gateway/sandbox/internal/workspacegit/`、`sandbox-gateway/sandbox/internal/router/`、`CHANGELOG.md`。
- 做了什么：每棵提交树通过一次有界 `git cat-file --batch` 读取小文件和链接，逐项校验对象身份、长度及链接范围；独立导入目录使用可继续提交的命名分支。未显式配置 `WORKSPACE_DIR` 的运行时不注册代码传输路由。
- 为什么：上千文件逐个启动 Git 会耗尽短租约；detached HEAD 不利于后续用户操作，缺少配置时使用进程当前目录会扩大访问范围。
- 如何验证：原生 Git 回归以 1200 个不同小文件证明只有一次批量进程，并验证安全链接与逃逸链接拒绝；保留 LFS、恶意配置、源脏文件和目标后续编辑回归。真实导入检查命名分支，路由测试验证缺少根目录时没有代码接口；另行继续验收可续租操作和实际停止证明。
