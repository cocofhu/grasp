# 2026-11-18（修复云电脑「我的电脑」快捷方式）

- 日期为 2026-11-18。
- 改动涉及 `sandbox-gateway/sandbox/scripts/`、`sandbox-gateway/sandbox/share/desktop/applications/` 和原有桌面测试。
- 底栏点击会用同一 Chromium 配置目录请求新建窗口。云电脑以 root 运行，Chromium 处理转发前需要和初次启动一样带上 `--no-sandbox`。缺少这个参数时，点击只在日志里留下错误。
- 快捷方式经镜像自带的入口调用当前运行时。热更新会刷新已生成的桌面项，让打开着的桌面使用新入口。
- 在运行中的桌面复现后安装修复，点击「我的电脑」确认同一 Chromium 实例打开了新窗口。桌面会话冒烟测试覆盖了旧快捷方式的刷新，镜像端到端测试增加了启动台窗口检查。
