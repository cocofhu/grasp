# 2026-11-09 独立评审本地对象存储启动组件

- 日期：2026-11-09
- 范围：`start.sh`、`scripts/local-objectstore.sh`、两套 Compose、环境示例与配置帮助。
- 做了什么：把缺省启动 SeaweedFS、私有持久目录、非 root 运行及 IAM 凭据保留收敛到独立的依赖改动层；应用正文存储协议与核心功能共用父分支。
