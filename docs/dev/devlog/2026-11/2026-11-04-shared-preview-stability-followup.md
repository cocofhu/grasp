# 2026-11-04（分享预览稳定连接后重置退避与语言应用去重）

- 日期：2026-11-04。
- 范围：`web/src/components/run/SharedAppPreviewChat.vue` 及其测试、`web/src/views/EmbedNodeChatView.vue` 及其测试。
- 做了什么：主会话连接收到有效快照后记录单调时钟时间，断线时仅在连接已持续健康至少 5 秒的情况下重置重连间隔；快照后立即出现 503 时保留指数退避。通过计算连接持续时间判断稳定性，不增加计时器。分享预览在激活会话时复用已经应用的 hash 语言，无 hash 时仍恢复会话语言；失效和网络错误页仍提前应用分享语言。
- 为什么：每次首帧都重置退避会让反复断开的连接持续按 1 秒重试。语言包已有缓存，重复的是语言加载入口和 i18n 状态应用；去重时需保留未能激活会话的错误页语言。
- 如何验证：覆盖快照后立即报错的连续重连、5 秒前后边界、持续尾部更新与没有有效快照的连接；语言用例验证打开和刷新各应用一次，以及失效／网络错误页继承语言且不改变全局偏好。Web 全量 6223 项单测通过，行覆盖率 91.71%；24 项定向测试和 29 项分享／预览 Playwright 用例通过。lint、类型检查、生产构建、文档构建与审计、actionlint 和 shellcheck 作为本次提交的本地门禁执行。
