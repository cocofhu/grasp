# 2026-11-22（首页、侧边栏与 CoCo 角色接入 A 方案表情）

- 日期：2026-11-22
- 范围：`web/src/components/dashboard/HomeYumeCharacter.vue`、`web/src/components/shell/BrandCharacterMark.vue`、`web/public/preview-pick.js`（及 `server/internal/handlers/`、`sandbox-gateway/sandbox/internal/previewinject/` 同步副本）、对应单测与 `web/e2e/live-variants.spec.ts`
- 做了什么：首页角色把原先随机的 look/ear/tilt/stretch 小动作换成按顺序循环的 12 个 A 方案状态（待机、开心、大笑、惊讶、困倦、生气、担心、思考、挥手、跳跃、奔跑、探头）。各状态由同一组眼睛、嘴、眉毛、手臂、尾巴和特效部件组合而成，靠 transition 交叉淡入并带回弹，循环动画都从静止姿态开始、在静止姿态结束，每个状态的停留时间是其循环周期的整数倍，所以切换时不会跳帧。悬停时挥手，输入框聚焦时回到待机，睡着时进入困倦，提交时跳跃，并保留原有的按压、跳起、翻转、爱心和点头。侧边栏小图标按顺序轮播看一看、开心、歪头、惊讶、眨眼、困倦，悬停时开心。CoCo 抽屉的图形与侧边栏图标保持一致，并用 48 秒一轮的 CSS 关键帧轮换同一组表情。角色轮廓按 A 方案从直线改为曲线：身体两侧微鼓、耳尖圆润、头顶柔和、下摆为 7 段浅波浪，尾巴从更低的位置伸出。表情特效（闪光、感叹号、Zz、汗滴、思考云、速度线等）使用项目主色 `--c-accent`（#7B61FF），嘴巴内部为白色（先后试过主色和粉色 #FF8FAB，都显得突兀），不跟随主色（首页、侧边栏和三份 `preview-pick.js`）。生气改为粗 V 字眉、半月形瞪眼和皱起的嘴；担心改为内端上扬的短眉、放大的高光眼；探头改为杆子挡在身体前、两只爪子抓杆、身体从杆后歪出，最终按 A 目标图（珊瑚红换成主色）细调：生气的眉毛压在瞪眼上沿、生气符号移到头上靠右耳处；担心的眼睛放大、汗滴为一大一小两滴，眉毛和眼睛一起跟随鼠标；探头的杆子缩短到眼睛高度以下，五官靠向杆子，右侧腮红隐藏。这条轮廓在 `media/`、`web/src/assets/brand/`、favicon、桌面图标、新标签页、启动页和三份 `preview-pick.js` 中同步替换。之后按用户给的 A 目标图更新 Logo 与动画连贯性：所有 Logo（`media/` 与 `web/src/assets/brand/` 的 SVG、favicon、桌面图标、新标签页、启动页涂鸦、侧边栏 `BrandCharacterMark` 和 CoCo）加上与首页相同的尾巴，画布从 `48 52 104 118` 扩为 `50 51 120 119` 给尾巴留位置，身体描边从 6 调到 5（favicon 保持 6）；尾巴下垫一条宽 9 的白色描边，浅底上看不出来，深色侧边栏和 `logo-dark.svg` 上尾巴不会消失。`grasp-logo-banner.png`、`favicon.ico`、`yume-mark.png` 由新 SVG 重新导出；`yume.svg`、`yume-mini.svg` 的尾巴换成新形状，摆动原点改到尾巴根部。表情切换从“两套五官同时交叉淡入”（中间会出现两张半透明脸叠在一起的灰影）改为“眨眼换脸”：旧部件约 0.12 秒内上下压成一条线并淡出，新部件延迟约 0.11 秒后带回弹张开，特效同样先退场再弹出；首页、侧边栏和 CoCo 关键帧（`/tmp/coco/gen2.py` 生成）用同一节奏，CoCo 与侧边栏悬停时尾巴摆动。桌面启动页吉祥物换成同一套造型：曲线身体、新尾巴、去掉珊瑚色内耳、ω 闭嘴和白色张嘴。
- 为什么：用户选定 A 方案作为角色，要求首页和 CoCo 等所有出现这个角色的地方都换上多表情和多动作，并且要连贯过渡而不是直接切换。
- 如何验证：`npx vitest run src/assets/brand`；`go test ./internal/desktop/`（sandbox）；`npx vitest run src/components/dashboard/HomeYumeCharacter.test.ts src/components/shell/BrandCharacterMark.test.ts src/lib/shared/previewPickScript.test.ts`；`npx vue-tsc --noEmit`；`npx playwright test e2e/yume-motion.spec.ts --project=desktop`；在 `e2e/live-variants.spec.ts` 中跑 CoCo 用例；`go test ./internal/handlers/ -run Preview`（server）与 `go test ./internal/previewinject/`（sandbox）。另在 Chromium 中逐个截取 12 个状态，并以 60fps 录制完整循环检查过渡帧。
