# 2026-11-09（停机等待旧 SQL 发布事务结束）

- 日期：2026-11-09
- 范围：`server/internal/database/{database.go,runtime.go,drain_test.go}`
- 做了什么：先关闭 SQL 连接池阻止新借用，关闭正文发布，再有界等待已借用连接、事务和游标全部归还，最后才删除运行登记。等待超时或取消保留维护排他登记，后续不会在后台自动解除；并发关闭调用各自遵守等待期限。删除登记使用同一原始截止时间的短控制连接，不重新迁移、创建正文存储或重连私有内存数据库。
- 为什么：`sql.DB.Close` 返回以后，先前借出的事务仍可成功提交。若立即移除运行登记，离线备份或迁移可能与旧发布事务并发，产生缺失正文或引用的快照。
- 如何验证：固定源码完整 server 测试、vet、lint、配置检查和 runtime 回归通过，server-core 覆盖率 90.1%；相关排空与维护回归 race 重复三次通过。真实 SQLite 和隔离 MySQL 8.4 上证明旧事务提交前仍保留运行登记、拒绝新借用及维护，归还后才解除。另验证超时后即使旧事务结束仍保留登记、并发关闭独立期限以及游标归还；MySQL 原生用例 race 重复三次通过，仅删除本次隔离测试容器与临时凭据。
