# 2026-11-04（分享聊天队列、回复统计与宿主图片弹窗）

- 日期：2026-11-04。
- 范围：`server/internal/{handlers,services}`、`web/src/{components/run,lib/inbox,lib/shared,views}`、`web/e2e`、`preview-pick.js` 三处副本。
- 做了什么：主会话分享从 Solo FIFO／工作流 dialogue turns 同步待发送队列，复用队列面板只读展示顺序、正文、批注与附件数量。快照携带队列，尾部增量只在队列变化时附带它，显式空数组清除队列。回复统计来自该条消息的执行快照、token 记录与耗时，不用当前模型设置回填旧回复；公开执行字段剔除 configuration ID，队列附件不暴露名称、地址或内容。独立聊天完成帧也携带实际报告的用量与耗时，未记录的字段保持缺失。分享附件预览接入现有跨 iframe 图片通道，图片地址仅通过同源 BroadcastChannel 传递；宿主遮罩和居中弹窗盖住整个 Page Harness 卡片，支持关闭按钮、遮罩与 Escape，图片 iframe 继承分享语言且不改变全局偏好。
- 为什么：分享链路只带聊天行和 busy 状态，遗漏队列及统计；分享图片使用了聊天 iframe 内部的弹窗，因此受到聊天区域尺寸和层级限制。
- 如何验证：定向 Go 竞态用例覆盖真实队列移除／排序、队列尾部增量和空队列、Solo／工作流统计投影、缺失与零用量、私有字段裁剪及独立聊天实际 WebSocket。Vue 用例验证队列增量合并、迟到 HTTP 快照、统计透传和宿主预览；注入器用例验证宿主层级、居中和关闭来源校验。真实浏览器分享用例验证手机／桌面图片窗口、语言、队列刷新与顺序、两种模式的统计与 token 零值。服务端完整门禁、运行时专项与核心覆盖率 90.5% 通过，沙箱门禁、注入器 smoke、核心覆盖率 96.6% 与运行时包构建通过。Web 全量 6224 项单测、行覆盖率 91.71%、lint、类型检查、构建，以及 29 项相关 Playwright 用例通过；文档构建与审计、actionlint、shellcheck 通过。PR CI 随提交重新验证。
