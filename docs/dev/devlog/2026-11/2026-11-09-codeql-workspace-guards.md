# 2026-11-09 工作区配置与对象键的静态检查收尾

- 日期：2026-11-09
- 范围：`server/internal/sandbox/reprime.go`、`server/internal/objectstore/s3.go` 及对应测试。
- 做了什么：复制运行环境时不再根据未限制的 map 长度加一计算分配提示；对象键用 `path.IsAbs` 表达禁止绝对路径，增加双斜杠和斜杠反斜杠来源的无网络拒绝验证。
- 为什么：消除 CodeQL 报告的分配长度溢出可能，并让对象键路径规则使用路径语义而非被误判成跳转检查的前缀表达式。原有相对路径与反斜杠限制继续生效。
- 如何验证：对象存储与沙箱包的既有测试和 race 检查；全量服务器检查在集成变更后运行，CodeQL 以推送后的实际结果为准。
