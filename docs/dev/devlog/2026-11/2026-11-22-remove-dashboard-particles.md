# 2026-11-22（移除首页粒子背景）

- 日期：2026-11-22
- 范围：`web/src/views/DashboardView.vue`、首页布局测试、粒子背景组件及共享实现
- 做了什么：移除 Dashboard 的粒子背景入口、画布样式、粒子控制器和对应测试，保留首页原有内容与交互。
