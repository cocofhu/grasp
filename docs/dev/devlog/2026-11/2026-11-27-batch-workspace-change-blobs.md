# 2026-11-27（批量读取工作区快照的 Git 对象）

- **日期** 2026-11-27
- **范围** `server/internal/sandbox/workspace_changes.py`、Git 快照回归、公开使用指南。
- **做了什么** 在同一对 Git 树上取得文件对象 ID，并复用两个批量进程读取对象大小和内容。补充 Solo 与工作流更改卡片的中英文用法。
- **为什么** 大批文本文件的前后版本读取需要在同一个归档时间预算内完成。批量协议只接收 Git 对象 ID，带制表符或换行的文件名也能正确定位内容。
- **如何验证** 实际 Git 仓库覆盖重命名、带分隔符的路径、二进制文件和超限文本。用同一份 2,010 个变更文件的样本比较两版采集，计数和前 2,000 个文件的载荷一致，本机耗时从 10.82 秒降到 2.38 秒。
