# 2026-11-09 工作区持久任务与可续期远端栅栏

- 日期：2026-11-09
- 范围：新增 `models/workspace_snapshot.go`、`workspace_restore.go`、服务/handler/client 的 workspace job 文件和沙箱运行时 `internal/workspacejob/`。
- 做了什么：建立应用级有界 worker、不可变任务意图、派发前标记、SQL/物理租约及远端续期协议。运行时以保留目录中的 fsync 校验日志记录资源、外部 lineage、代次高水位与收据，跨进程锁避免重复所有者。独立看门狗按最后确认的到期时间停止本机执行，父进程退出也清理子进程组；重复创建只读原收据，不续期或重放。未知派发只允许显式读取原收据核对。
- 为什么：完整文件复制可能超过单次 45 秒租约，不能延长到无限请求或在页面关闭后遗留无主进程。SQL 回滚不能成为重置远端代次的权限，因此服务必须显式注入外部 Authority；没有 Authority 时保持拒绝执行。
- 如何验证：真实 shell 任务运行 50.021 秒，经 24 次 HTTP 续期完成；真实 SIGKILL 后子进程退出，重启保留未知收据且不重放。短 TTL、多轮续期、阻塞 fsync、所有者替换等待、过期不复活、SQL 瞬时错误、浏览器断连和晚到响应均经 race 三轮验证。隔离源码后端全量/vet/lint/core 90.1% 与沙箱全量/vet/lint/core 96.6% 通过。默认采集/恢复 executor 仍为空、文件能力为 false；本次仅完成控制协议，不发布 ready 文件快照或恢复成功状态。
