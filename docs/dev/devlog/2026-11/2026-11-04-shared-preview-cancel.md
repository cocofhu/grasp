# 2026-11-04（分享聊天支持停止当前回复）

- 日期：2026-11-04。
- 范围：`server/internal/handlers/app_preview_{cancel,guest,share_test}*.go`、`server/internal/router/router.go`、`web/src/components/run/SharedAppPreviewChat*`、`web/src/lib/inbox/appPreviewShare*`、中英文语言包、`web/e2e/conversation-workspace.spec.ts`。
- 做了什么：分享聊天处理消息时显示停止按钮，主会话调用受分享凭证、CSRF、聊天模式和工作流轮次约束的取消接口，沿用 Solo、澄清和评审各自的队列处理策略。独立会话使用逐轮 ID 和独立取消上下文，读取协程立即处理取消，即使回复尚未开始也可中断；等待运行时取消确认后通过原连接发送终止帧。迟到的取消不会影响下一轮或其他访客，已生成内容和输入草稿保持，主动中断不再显示发送失败。运行时无法确认取消而失步时，下次发送重建独立聊天，并恢复包含中断片段的有限历史。
- 为什么：分享聊天只有发送按钮，后端独立会话读取器也未区分取消指令，正在处理时无法中断。取消必须到达真实执行回合，并保留后续继续聊天的能力。
- 如何验证：真实桥接 WebSocket 测试覆盖首字前／部分输出后的中断、对应运行时操作 ID、原连接继续发送和迟到取消隔离。接口回归覆盖 Solo、工作流评审和澄清，以及独立链接越权、跨来源、撤销凭证、旧轮次和服务不可用分支；重点用例通过 race detector。组件用例验证取消等待、重试、草稿与部分输出保持。35 项浏览器回归、Web 全量 6239 项单测（行覆盖率 91.85%）、lint、类型检查和生产构建通过；服务端完整测试、lint、vet、配置文档检查、运行时回归及 90.5% 核心覆盖率门禁通过；文档构建／审计和 actionlint／shellcheck 通过。
