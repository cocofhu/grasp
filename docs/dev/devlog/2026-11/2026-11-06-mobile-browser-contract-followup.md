# 2026-11-06（修正移动端浏览器测试入口）

- 日期：2026-11-06
- 范围：`web/playwright.config.ts`、`web/package.json`、`web/e2e/`、`CONTRIBUTING.md`
- 做了什么：将默认 E2E 命令限定为完整桌面套件，各移动端矩阵保留独立命令。用 `E2E_PORT` 同时配置 Vite 和测试用的 URL。登录用例以未登录用户打开页面，并等待用户名与密码输入框出现后检查缩放。
- 为什么：已有服务占用默认端口时仍可运行 E2E，默认命令避免重复执行移动矩阵，并确保登录用例实际检查登录表单。
- 如何验证：用备用端口运行 Chromium 登录用例，用 Playwright 的 `--list` 检查默认命令选择的项目。
