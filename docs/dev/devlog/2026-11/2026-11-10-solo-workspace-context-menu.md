# 2026-11-10（Solo 工作区操作收进右键菜单）

- 日期：2026-11-10
- 范围：`web/src/components/shell/`、`web/src/components/solo/`、`web/src/views/SoloView.vue`、`web/src/locales/{zh-CN,en}/workspaceSnapshots.json`、`web/e2e/workspace-snapshots*`、`CHANGELOG.md`
- 做了什么：移除 Solo 对话上方的工作区工具栏，在侧栏 Solo 右键菜单加入快照与停止／恢复环境；已关闭的历史会话也能通过右键查看快照、打开释放环境。菜单支持键盘和手机长按，兼容点击保护从松手时开始计时，持续按住再松手也不会关闭菜单或误跳转，滚动不会触发菜单。快照及工作流快照统一使用居中弹窗，支持 Escape 和焦点约束。将历史卡片收紧为列表，移除操作介绍、保存说明和重复的成功状态；异常及切换确认仍按实际状态显示。停止环境保留执行中、队列和请求中的限制，已停止的环境可带着保留队列恢复。
- 为什么：低频工作区管理操作不应常驻聊天区；使用清晰的入口、按钮与状态表达功能，减少重复说明和卡片层级。
