# 2026-11-03（稳定首条澄清消息与会话队列）

- 日期：2026-11-03。
- 范围：`server/internal/engine`、`server/internal/chatsession/session_test.go`。
- 做了什么：澄清节点只自动重答进入节点时已存在且仍未回答的消息。首条消息引用测试等待队列发布终态，异常恢复测试确保两条消息在首轮触发异常前已进入同一个队列。快照断言在不匹配时显示实际内容。
- 为什么：节点开放时刚入库的用户消息可能被当成续跑遗留消息，从而触发额外回复。快照日志显示原对话后出现多余的重试。首条消息入库也早于 Agent 收到 prompt，两个测试各自需要等待对应阶段。
- 如何验证：引用测试启用竞态检测重复运行 120 次。异常恢复测试启用竞态检测重复运行 1000 次。用实际对话快照覆盖打开、回复、停止和重试，并检查取消后续跑保留原对话。
