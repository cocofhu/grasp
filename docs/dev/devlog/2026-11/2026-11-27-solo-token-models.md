# 2026-11-27（Solo 累计 Token 显示模型明细）

- 日期：2026-11-27
- 范围：`server/internal/services/solo_task_info.go`、`web/src/components/sandbox/`、相关 API 类型、文案和测试、`CHANGELOG.md`
- 做了什么：按用量账本中的模型标识汇总整个 Solo 会话。悬浮在累计 Token 上可以查看各模型的小计及输入、输出、缓存读和缓存写。已上报但缺少模型归属的用量计入「未知模型」。
- 为什么：同一个会话切换模型或重建沙箱后，仍可查看累计用量来自哪些模型。
- 如何验证：后端接口测试覆盖跨沙箱汇总和无模型归属的记录。面板单测和 Chromium 用例验证分项明细、浅色和深色主题及键盘关闭。
