# 2026-11-09 清理版整合当前 Solo 运行时

- 日期：2026-11-09
- 范围：`server/cmd/server/main.go`、`CHANGELOG.md` 与迁移版分支合并。
- 做了什么：把当前迁移版的原生任务接回、工作区租约、保留环境恢复和诊断修复整合到清理版；启动时仍先执行只读格式检查，再打开可变数据库运行时。
- 为什么：清理版必须建立在最终迁移版能力之上，既移除运行时历史格式回退，又保留离线核对后按当前授权恢复原环境的正式流程。不能因为删除旧版兼容读取而同时删除恢复与权限保护。
- 如何验证：核对只读格式检查先于 `database.OpenRuntime`；保留执行来源与原生授权依赖。实际合并仅启动入口与变更记录需要同时保留两侧修改；后续完整模块检查和真实数据升级验收另行记录，当前合并不视作发布验收完成。
