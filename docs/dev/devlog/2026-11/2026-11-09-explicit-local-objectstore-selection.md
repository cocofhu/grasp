# 2026-11-09 本地对象存储要求显式选择

- 日期：2026-11-09
- 范围：`scripts/local-objectstore.sh`、`start.sh`、初始化与组件测试、`.env.example`、中英文配置帮助、`CHANGELOG.md`。
- 做了什么：只有同时选择 S3 和 `GRASP_LOCAL_OBJECTSTORE=1` 才允许配置空地址的本地 SeaweedFS；遗漏、关闭或无效选择在创建本地目录、启动组件和初始化前失败。重启先检查，再停止原服务。外部地址始终沿用外部存储，恢复入口仍可停止组件。
- 为什么：地址遗漏和实例身份认证配置不能被误解为建立空白存储的意图。保留原本地身份和对象仍是恢复前提。
- 如何验证：本地组件与启动器回归覆盖缺失选择、无效值、外部地址、部分云凭据、停止前拒绝及原身份重复启动；运行根门禁和文档构建、审计，另用公开启动入口验证真实 SeaweedFS 重启后对象及凭据保持。
