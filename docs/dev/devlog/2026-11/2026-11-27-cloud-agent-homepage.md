# 2026-11-27（云端 Coding Agent 官网与帮助）

- 日期为 2026-11-27。
- 范围包括 `docs/scripts/`、`docs/site/`、中英文帮助首页与网关帮助和 `CHANGELOG.md`。
- 首页用浅色运行环境插图展示四种连接方式。切换封面或架构图会同步命名网关示例，配置按需展开。工作区随滚动从 Solo 请求过渡到页面预览和 SSH 接手，访客可以自行放大产品截图。模型组的 8 种 CLI 与独立运行时的另外 10 种适配分别展示。
- 中文使用 IBM Plex Sans SC 的本地子集，展示标题使用 Geist，字标沿用项目的 Fredoka 和官方幽灵猫。搜索框用输入行的细底线表示焦点，键盘可以直接打开配置字段。
- 帮助首页用书脊链接直达快速开始、配置索引和故障排查。目录条目在悬停时只改变底色、文字颜色和箭头位置，固定内边距，避免长摘要重新换行。文章可通过面包屑返回所属目录。移动端配置参考沿用同一张表的字段和列名，纵向展示变量、默认值与用途。
- 这些调整让访客先看懂自托管 Agent 的工作区和接入方式，再决定是否阅读部署细节。工具范围对照 `server/internal/runtime/acp_backend.go` 和沙箱运行时注册表。
- 验证涵盖 36 个中英文页面、域名根路径和项目路径、npm 高危审计、品牌检查、actionlint、shellcheck 和两组 CI 脚本回归。浏览器检查运行环境与配置联动、键盘与触屏操作、滚动及回退、图像放大、配置搜索、关闭 JavaScript 和减少动效。
- 帮助目录在 Chromium（320 至 1536 像素）和 WebKit（390、940 像素）逐项核对了 16 个入口。悬停前后、过渡结束和键盘聚焦时，每项的位置、文字宽度和高度均相同。
