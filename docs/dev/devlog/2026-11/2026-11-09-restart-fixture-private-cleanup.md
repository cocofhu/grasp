# 2026-11-09 重启验收正确清理容器创建的私有目录

- 日期：2026-11-09
- 范围：`server/e2e/restart_reattach_test.go`、`server/e2e/restart_cleanup_test.go`
- 做了什么：Compose 确认关闭后，使用相同发布镜像的 Node 在一个无网络、只读根文件系统的临时容器内，只挂载并清空本次测试专有目录。随后由 runner 删除空目录。目录名、父路径、真实目录检查不通过时拒绝清理；Compose 关闭失败也保留数据并报告错误。
- 为什么：执行初始化会按真实安全合同创建 root 所有的 0700 控制和维护目录。非 root CI runner 无法遍历这些目录，原来的 `os.RemoveAll` 因而在原生重启测试结束时报 permission denied。修复不放宽真实目录权限，也不改自动续接的运行状态与单次执行断言。
- 如何验证：带 `e2ereal` 标签的清理回归在 `-race` 下通过，真实 Docker 创建 0700 私有目录后能清理本次目录，同时保留目录外的符号链接目标；纯参数回归验证唯一可写挂载及越界、空镜像和替换符号链接拒绝。此项只修测试清理，未把原有 paused 续接失败判为成功。
