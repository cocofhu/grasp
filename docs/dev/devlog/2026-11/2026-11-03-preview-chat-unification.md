# 2026-11-03（统一预览聊天并支持拖动工具条）

- 日期：2026-11-03
- 范围：`web/src/components/{solo,run}/`、`web/src/views/EmbedNodeChatView.vue`、`server/internal/{handlers,services,sandbox}/`、`preview-pick.js` 三处同步副本。
- 做了什么：Solo 浮层直接复用正式会话组件和聊天请求契约。工作流和匿名分享复用聊天输入区和模型控件，预览凭证只读取该会话可用的模型目录。匿名主会话沿用原会话的模型设置，独立会话只修改访客自己的沙箱聊天。统一工具条新增拖动手柄、键盘移动和页面刷新恢复位置。
- 为什么：预览中的独立输入框漏掉了模型选择，也无法继承正式聊天的队列和附件体验。直接预览的工具条需要能移开，便于操作页面。
- 如何验证：Playwright 覆盖 Solo、工作流和匿名两种模式的模型切换及工具条拖动。Go 用例校验预览凭证作用域、模型目录脱敏、附件归属和独立聊天切换。
