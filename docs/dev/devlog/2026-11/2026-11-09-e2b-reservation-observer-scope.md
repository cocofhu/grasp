# 2026-11-09（E2B 端口恢复测试限定实例与观察期）

- 日期：2026-11-09
- 范围：`sandbox-gateway/gateway/internal/driver/e2b/endpoint_reservation_test.go`。
- 做了什么：端口预留测试为恢复实例使用独立 HTTP 观察入口，在旧实例仍占用全部端口时创建该入口；关闭实例前同步结束观察段，避免将旧实例的迟到请求或关闭后回调当成恢复请求。每条被观察的请求仍真实尝试绑定全部 12 个保存端口，并要求存在正向请求观察；新增旧入口不被计入的核验。
- 为什么：取消 HTTP 客户端请求并等待驱动维护循环退出，不等于远端 HTTP handler 已经完成；`Close` 返回后端口按契约释放，原全局回调仍可能观察这些迟到请求而误报。该 E2B 包在当前主分支与修复基线内容一致，本次不修改生产驱动或恢复顺序。
- 如何验证：自然重复原测试 race 100 轮及双核 1,000 轮未重现单次 CI 失败；通过可控真实 HTTP handler 屏障稳定 5 轮确认取消请求可在关闭后继续执行且 12 个端口已释放。限定观察范围后 race 100 轮通过；故意恢复旧的逐环境预留后请求顺序，真实绑定断言仍报告 6 个未预留端口并失败。网关全量 race、lint、vet 及覆盖率 90.4% 通过。测试使用本地 provider 协议夹具，不请求 E2B Cloud 或付费模型。
