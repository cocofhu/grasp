# 2026-11-27（将工作区切换放到文件统计旁）

- **日期** 2026-11-27
- **范围** `web/src/components/changes/`、中文与英文界面和使用指南、`web/e2e/workspace-changes.spec.ts`。
- **做了什么** 查看器在文件统计旁显示带「工作区」标签的选项。同名选项附带快照时间。工作区加载成功后，选择和文件统计一起更新，失败时可以重试同一个工作区。
- **为什么** 「实现」这类节点名需要明确的查看范围。用户切换工作区时可以对应查看同一份快照的文件和统计。
- **如何验证** 浏览器覆盖键盘切换、收起菜单后恢复焦点、加载失败后重试、单工作区与本轮视图，以及深色窄屏下的菜单位置。
