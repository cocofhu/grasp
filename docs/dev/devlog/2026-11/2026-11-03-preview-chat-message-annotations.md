# 2026-11-03（预览聊天正文与取点分离）

- 日期：2026-11-03
- 范围：`web/src/components/{chat,run,solo}/`、`web/src/lib/`、`server/internal/{handlers,engine,services,models}/`、`preview-pick.js`。
- 做了什么：预览聊天以正式的标注结构发送取点。Solo 持久化并在排队、撤回编辑与重连时保留标注，工作流和访客会话继续把标注上下文提供给 Agent。聊天气泡把取点显示为标签，也能回放旧版本附加在正文末尾的取点块。分享浮层与 Solo 共用输入框、占位内边距、附件与 @ 交互，也复用等待提示、流式回复和滚动。匿名访问只查询公开 GitHub 引用，主会话分享历史只公开从该分享入口发送的附件。
- 为什么：分享链接与新标签直开进入同一个应用页面时，浮层的初始状态和输入能力不一致。发送取点后，机器生成的标题和 CSS 选择器也会显示成用户正文。
- 如何验证：浏览器用例覆盖 Solo 及两种匿名模式的发送和历史显示，组件用例覆盖旧消息与队列编辑，Go 用例校验标注持久化、Agent 输入和公开历史脱敏。
