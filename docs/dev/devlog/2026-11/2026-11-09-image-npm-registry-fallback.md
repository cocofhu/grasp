# 2026-11-09 镜像构建在 npm 镜像站故障时重试官方源

- 日期：2026-11-09
- 范围：`server/Dockerfile`
- 做了什么：镜像构建仍优先使用仓库配置的 npm 镜像源，将该次安装的重试次数限制为两次；失败后使用官方 registry 重新执行 `npm ci`，沿用同一 lockfile 和完整性校验。
- 为什么：分支镜像实测遭遇镜像站下载接口持续 HTTP 500，依赖无法安装，阻断运行时修复的真实沙箱验收。
- 如何验证：检查 Dockerfile 只更改依赖获取路径，重新执行固定提交的完整分支镜像构建；模块源码与已有通过的运行时、服务端和前端验收来源保持一致。
