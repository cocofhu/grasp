# 2026-11-11 移除独立执行控制存储并统一 SQL 离线恢复

- 日期：2026-11-11
- 范围：`server/cmd/server/`、`server/cmd/storage-admin/`、`server/internal/{config,executionlineage,models,objectstore,payloadstore,chatsession,engine,handlers,services,payloadhold}/`、`server/e2e/`、当前存储/升级/配置文档、双语 README 与帮助页、`CHANGELOG.md`。
- 做了什么：移除独立控制存储的配置、环境解析、条件写与控制对象读取；服务与离线工具统一使用既有 SQL 执行绑定、维护锁和持久恢复记录。原私有维护目录保留 v2 票据、配置/备份/目标身份及单调恢复阶段，完成回执固定实际导入绑定；同一操作中断可续办，完成票据不能在 SQL 回滚后再次激活。运行进程在事务内核对启动绑定，长时间正文准备不新增过期限制。保留业务本地/S3/COS 存储、历史关联和旧任务隔离，并兼容尚无执行绑定的旧备份恢复。
- 为什么：普通本地运行和离线维护都不应依赖额外的对象存储服务；删除外部执行标记时仍须防止错误续办、提前解除维护和自动重发结果不明的旧任务。旧版外部控制票据必须用原工具完成，已有对象与 Secret 不自动删除；全部写入者停机和原维护目录仍是恢复前提，直接覆盖 SQL 不具备独立防回滚能力。
- 如何验证：服务器 `go test ./...`、`go vet ./...`、golangci-lint、配置文档生成校验与 Agent/React 回归通过；核心覆盖率 90.2%（门槛 90%）。SQL 恢复包竞态三轮、业务对象存储竞态、空安装 S3 绑定和队列隔离竞态通过。离线 CLI 覆盖原绑定保留、旧票据拒绝、无对象存储访问、中断重试、备份篡改、维护释放旁路、完成票据回滚重用和不同来源代次。仓库 gate、文档构建与审计通过；Docker 所有权回归仅运行不依赖真实镜像的部分，未部署服务或删除存储。
