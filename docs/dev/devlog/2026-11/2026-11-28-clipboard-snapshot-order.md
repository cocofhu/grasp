# 2026-11-28（接管后立即复制的剪贴板顺序）

- 日期：2026-11-28
- 范围：`server/internal/handlers/preview_vnc.go`、`web/src/components/run/NovncPreviewPanel.vue`、回归用例、`CHANGELOG.md`
- 做了什么：收到可能触发复制的输入时，只锁定此前已完成的剪贴板快照。粘贴时再读取当前所有权和版本。没有可比的基线且远端已有所有者，或探测超时时，直接转发远端粘贴。
- 为什么：接管探测可能在远端应用完成复制后才取样，使用该快照比较会漏掉复制，继而使用本机文本覆盖远端内容。
- 如何验证：回归用例控制版本从 7 更新到 8 之后才让接管探测取样，覆盖有复制和无复制两种输入，并检查输入无需等待探测。Playwright 覆盖探测超时时仍保留远端粘贴。
