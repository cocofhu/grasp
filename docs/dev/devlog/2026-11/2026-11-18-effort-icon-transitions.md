# 2026-11-18（思考强度弹层的图标过渡）

- 日期：2026-11-18
- 范围：`web/src/components/solo/SoloModelSelect.vue`、`web/e2e/model-routing.spec.ts`
- 做了什么：闪电与恢复箭头在悬停、键盘聚焦和按压时通过 CSS 变换反馈。Fast 切换时淡入或淡出闪电填充；点击恢复时箭头在 360 毫秒内转一圈。系统启用减弱动态效果时直接切换到最终状态。
- 为什么：让用户能看出按钮可操作，也能看见切换 Fast 或恢复默认档位的反馈。
- 如何验证：在 Chromium 中检查可用按钮的过渡、Fast 透明底色、恢复默认档位以及减弱动态效果下的键盘操作。
