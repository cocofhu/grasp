# 2026-11-11（Solo 关闭不再阻塞弹窗）

- 日期：2026-11-11
- 范围：`web/src/components/shell/AppSidebarNav*`、`web/src/components/solo/SoloSessionPane.vue`、`web/src/lib/solo/useSolo{Sessions,Chat}*`、`web/src/locales/{zh-CN,en}/pages.json`、`web/e2e/solo-close.spec.ts`、`web/package.json`、`CHANGELOG.md`
- 做了什么：确认关闭后立即收起弹窗，保留后台停机请求，以侧栏状态、当前聊天提示和持续通知展示进度；成功与失败分别反馈。关闭请求在桌面侧栏和手机抽屉之间共享并去重，期间禁止向该会话继续发送或重复停启，其他会话及取消运行操作仍可使用。失败后重新读取服务端状态，不自动重放；旧列表和旧会话读取不能覆盖关闭结果，离开页面后的会话读取不再回写侧栏，关闭与首次加载竞争时补齐新读取，清理并发模型设置请求的等待状态。弹窗支持 Escape、取消、关闭按钮和焦点约束。
- 为什么：原流程等保盘停机完成后才收起确认弹窗，期间共用取消运行的忙碌状态锁住按钮，用户只能面对没有进度的禁用按钮。实际停机仍须等待服务端确认，交互可以立即释放并明确展示尚未完成。
- 如何验证：前端 lint、类型检查及生产构建通过；全量 601 个单测文件、6473 个用例通过，行覆盖率 91.68%。定向回归覆盖慢请求、重复关闭、其他会话、抽屉卸载、停机未确认、旧列表／会话响应、模型设置及初始加载竞争；离开页面后旧读取覆盖关闭状态的用例确认修复前失败、修复后通过。新增三项 Playwright 覆盖桌面慢停机、失败核对及手机抽屉切换，在响应未返回时检查弹窗已收起，最终全部通过。完整浏览器套件共 399 项，首轮 396 通过、3 项失败；Solo 失败项修复后随新增三项复测通过，产物 768px 与确认流转 200px 两项单独复测通过。仓库 CI 工具下载、actionlint、shellcheck、文档发布传输回归，以及 docs 构建和 audit 均通过。
