# 2026-11-09 预览切换忽略已退役工作区的旧入口

- 日期：2026-11-09
- 范围：`server/internal/mcp/preview.go`、对应 stale displacement 回归
- 做了什么：切换当前工作区的预览 injector 时，跳过服务端已判定 `Stale` 的旧工作区记录，不探测、重新发布或改写这些旧入口。当前有效工作区的旧预览仍必须通过原有独立发布和可达性检查；新入口仍须通过最终绑定校验。
- 为什么：实际 Kubernetes 验收中，激活恢复副本并停启原环境后，真实 Agent 的当前目录与文件均正确，但 `set_preview` 被先前工作区已失效的旧端口阻断。该入口已经由绑定感知代理拒绝访问，不应参与当前工作区的预览置换。
- 如何验证：回归覆盖旧工作区不可达端口不阻断新预览、旧记录没有被重新发布、当前有效旧端口失败仍阻止切换，以及 injector 切换期间绑定变化不能发布新入口。另重跑已有 displacement、private preview 和绑定校验测试；实际 provider 复验须在该修复部署后进行，原先已完成的消息与停启请求不重放。
