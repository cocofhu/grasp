- 做了什么：`status=queued` 的 Run 从「正在执行」移到「自动过程」下方的新分组「排队中」（Queued），可折叠并沿用原 localStorage 键持久化，带计数与 `queue` 图标，组内支持置顶，无排队 Run 时隐藏；「正在执行」计数不再包含 queued。queued 行不写入 `paintedGroups`，进出排队中直接换位，不播放飞入动画。
