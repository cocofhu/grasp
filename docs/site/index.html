Grasp

Agent 工作流与人类协同推进， 开启多Agent协作新范式。

能力

  • 可视化编排 画布 FSM、运行态高亮；多需求并行泳道，门禁 Inbox 收口审批。
  • 真实 Docker 沙箱 经 ACP 与 sandbox-gateway 在容器中执行，Web UI 走 API。
  • 多 Agent 后端 Cursor、Claude Code、CodeBuddy、Trae；按 Agent 选择 acpBackend。
  • 产物契约 + MCP write_artifact / set_* / node_complete；按 run token 隔离。
  • 项目凭据与沙箱 Git 项目凭据 UI 优先管理 GITHUB_* / GITLAB_* / SSH；兼容 env 回退，GitLab auto-MR 与 GitHub gh 可用。
  • 单仓自托管 sandbox-gateway 与沙箱镜像源码在本仓库，一次克隆即可。
