## 创建会话 {#create}

在首页选择 Solo，挑选 Agent、模型及任务需要的仓库，然后发送第一条消息。没有仓库也能开始对话。如果这是第一次使用，先[配置模型组](/guide/first-run/#model)。

会话使用持续的沙箱工作目录。要了解 Agent 实际执行的操作，查看回复旁的运行信息和工具记录。可从会话打开终端、浏览器 IDE 或预览，方便检查当前改动。应用出现在预览中前，需要在沙箱里启动对应服务并登记预览，连接方式由部署策略决定。

## 切换模型和工具 {#switch-model}

模型选择器列出 Agent 已绑定的模型组，以及组内可选的主模型和辅助模型。默认选中默认组的主模型。选中的组决定本轮使用的工具、凭据和推理配置。

进行中的一轮按原选择完成。新选择从下一轮生效。跨工具切换时，Grasp 保留工作目录和未提交改动，并把平台记录的对话上下文交给新工具。需要更早信息时，Agent 可以通过 Grasp 工具读取历史。某些环境或凭据变更会提示重新打开会话。

## 打开终端、预览和 IDE {#tools}

- **终端**用于运行命令并查看沙箱里的文件和进程。
- **预览**用于打开 Agent 已登记的应用。启用代理或子域名等方式取决于[网关与预览配置](/help/gateway/#preview)。
- **本地 IDE**在管理员启用 SSH 网关且你登记公钥后可用。按[本地 IDE 指南](/help/local-ide/)连接。
- **附件**可拖入或粘贴到输入区域。单文件上限 50 MiB。工作流聊天和 Agent 测试也能使用同套附件操作。

## 停止、恢复与关闭 {#lifecycle}

在会话顶栏的沙箱信息里查看环境和状态。暂时离开时用「停止」保存环境并释放资源，之后用「恢复」继续。文件归档与 E2B 快照保留的状态不同，详见[沙箱生命周期](/help/sandbox-lifecycle/)。

关闭会话会清理环境和恢复点。需要保留的代码先提交到仓库，或从沙箱导出。容量满时先查看已停止与仍占用名额的沙箱，再决定恢复哪个会话。
