## Agent 与模型组 {#agents}

Agent 定义这项工作要用的指令、能力和工具。模型组选择实际执行的编码工具、授权和模型。一个 Agent 能绑定多个组，也能继承默认配置。仓库记录单独指定 Git 授权。见[模型组与智能体](/help/agents-models/)。

## 工作流、运行与人工门禁 {#workflows}

工作流是一张已定义步骤和跳转条件的图。发布后的版本可供启动。一次运行记录输入、活跃节点、对话和产物。人工门禁让运行在指定节点等待决定，随后按连线继续。运行页、待办和产物页都能帮助你追踪这次工作。

## Solo 与沙箱 {#sandboxes}

Solo 是一个可以继续对话的任务会话。Solo 和工作流都在由 Gateway 管理的沙箱里执行。沙箱提供工作目录、终端和可选的 IDE 与应用预览。网关决定镜像或模板，Grasp 管理会话与工作流在何时请求环境。见 [Solo 会话](/guide/solo/)和[沙箱生命周期](/help/sandbox-lifecycle/)。

### 远程桌面粘贴 {#desktop-clipboard}

接管沙箱的「浏览器」或「电脑」后，点选远端输入框，按 `Ctrl+V`（macOS 用 `⌘V`）即可粘贴本机纯文本，单次最多 128 KiB。用快捷键在画面里复制、剪切并更新沙箱剪贴板，或在工具栏选「放入沙箱剪贴板」后，画面保持焦点时会粘贴沙箱剪贴板的内容。焦点离开画面后，优先使用本机文本。本机剪贴板没有文本时，会尝试粘贴沙箱里的内容。

也可以打开工具栏的「剪贴板」，输入或粘贴文本后选择「粘贴到当前窗口」。在电脑沙箱的终端中，先勾选「终端粘贴（Ctrl+Shift+V）」。终端里用 `Ctrl+C` 中断任务后，仍可直接从本机粘贴。

## 查看工作区改动 {#workspace-changes}

在 Solo 和工作流运行详情的右上角打开 **更改**，可按仓库查看分支和累计增删行。点击一个仓库进入逐文件差异。累计改动以会话或运行首次检出为基准，提交代码后仍计入统计。工作流释放沙箱后，可以继续查看最近归档的版本。有多个工作区时，在文件统计旁通过 **工作区** 切换，列表和增删行数随选择更新。

输入框上方的 **本轮改动** 对比最近一轮开始前和结束后的文件。对于可识别的代码类型，差异同时显示语法高亮和增删行标记。查看器支持文本源码和 Markdown 预览，删除的文件可以查看删除前的内容。

## Solo 对话里的 @ 引用 {#references}

在 Solo 输入框（包括首页启动新会话的输入框）输入 `@` 搜索，或点「+」选择要引用的类型。

- **你自己的其他 Solo 会话**：按标题搜索，已关闭的会话也能引用。发送后，Agent 会先看到被引用会话里用户要求的摘要；需要完整对话时，它用 grasp-tool 的 `read_reference` 分页读取。内容固定在这轮开始时的快照，之后被引用会话里的新消息不会混进来。
- **GitHub issue / PR**：在当前会话挂载的 GitHub 仓库里搜索（首页启动时按已选的仓库搜索），输入 `#编号` 或粘贴 issue / PR 链接也可以。平台用沙箱同一份 Git 凭据检查能否访问；Agent 在沙箱里用 `gh` 读取最新内容、评论和改动。
- **GitHub Discussion** 支持按关键词或编号搜索。仓库凭据需要有读取讨论的权限。也可以直接粘贴讨论链接。Agent 可以免登录读取公开页面上的正文、采纳答案和可见回复。读取私有讨论时，每次都使用目标仓库的凭据，按评论和楼中回复各自的分页读取。
- **工作区产物** 可按文件名搜索。发送时会记下版本，之后从消息打开文件或由 Agent 用 `read_reference` 读取文本摘录、下载原文件，都会使用这个版本。

用 `↑` `↓` 选择，`Enter` 确认，`Tab` 切换类型，`Esc` 关闭。手机上可以直接点「讨论」或「产物」，切换类型后也能继续输入关键词。没有选中项时按 `Enter` 照常发送。每条消息最多引用 5 个，选中的引用显示在输入框上方，删掉 `@标题` 文字或点 × 都会去掉引用。Agent 只把引用的内容作为资料。

工作流里也能这样引用：

- 在**首页「工作流」输入框**中，选中工作流后输入 `@` 或点「+」。GitHub 引用在该工作流绑定的仓库里搜索。没有配置仓库时也能搜索会话和产物。只带引用、不写文字也能启动，运行标题取第一个引用。切换工作流或切回 Solo 时，已选的引用会清掉，文字保留。
- 在**运行内的澄清、复审对话和审批热修订**中，GitHub 引用在这次运行克隆的仓库里搜索。当前节点的 Agent 用 `read_reference` 读取会话和产物。它在沙箱内读取 GitHub 引用，重读讨论时仍按目标仓库选择凭据。节点结束、未激活或输入框锁定时不能引用。匿名分享的审批页不提供引用。

## 产物与工具 {#artifacts}

产物是工作流节点读写的任务数据，例如需求、计划、测试报告和附件。下游步骤可以引用上游产物。Grasp 的内置工具把适用的工作流、对话和产物操作提供给 Agent。可在「设置 → 集成」查看内置工具目录。
