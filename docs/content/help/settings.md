打开「设置 → 常规」。数字字段会显示来源。环境变量锁定的项目在页面上只读，修改部署配置后由管理员重启对应服务。

## 沙箱空闲回收时间 {#sandbox-idle}

**默认 360 分钟，最小 1 分钟。** 仅对 E2B 环境的自动回收生效。完整模型回合结束且队列为空后开始计时。访问网页、预览或普通终端不续期。通过 Grasp SSH 网关连接本地 IDE 时，回收会等待最后一个连接断开，再开始新的计时。

改动影响后续空闲检查。在 Solo 的沙箱信息里核对倒计时和环境类型。单次会话可选「永不自动回收」或当前界面的「保持运行」。Docker 和 Kubernetes 通过手动停止、关闭或取消释放环境。YAML 对应 `sandbox.idle_ttl_minutes`。

## 最大同时运行沙箱数 {#sandbox-capacity}

**默认 15，最小 1。** 所有用途和后端共用。创建中、运行中和仍在释放资源的沙箱占用名额。达到上限后会限制新建和恢复，新的工作流运行可排队。该值也用于工作流并发控制。

保存后查看「沙箱占用 / 上限」。降低上限后，现有工作可以继续，直到释放足够名额才能接纳更多。YAML 对应 `sandbox.max_sandboxes`。

## 沙箱内存覆盖 {#sandbox-memory}

**默认 0，跟随网关或模板。** 非零值至少 1024 MiB，作用于之后新建的沙箱。Docker 和 Kubernetes 的值须符合网关资源上限。E2B 的值须与选中模板规格一致。浏览器、构建和 Agent 共用该环境的内存。

保存后新建一个沙箱并检查规格。填回 `0` 清除覆盖。YAML 对应 `sandbox.sandbox_memory_mb`，环境变量 `GRASP_SANDBOX_MEMORY_MB` 可锁定界面。

## Agent 无动作时限 {#agent-idle}

**默认 20 分钟，界面范围 2–120 分钟。** 连续没有输出、CPU 和磁盘活动达到时限后，系统先尝试恢复一次，持续无动作时结束当前回合。保存后从下一轮开始使用新值。

可在运行详情看到因无活动结束的回合。画布上配置的节点总时限和等待沙箱就绪的超时是独立参数。YAML `sandbox.chat_idle_timeout_seconds` 和环境变量 `GRASP_CHAT_IDLE_SEC` 以秒计。

## 工作区和品牌字段 {#workspace-brand}

| 字段 | 修改后影响 |
| --- | --- |
| 工作区名称和描述 | 更新工作区展示信息。 |
| 未知模型显示名 | 用量统计、图例和运行明细的显示标签。最多 64 字符，留空使用默认名称。已记录用量保持原归属。 |
| 产品名 | 管理员可改侧栏与首页共用的产品名称，最多 40 字符。留空使用 Grasp。 |
| 首页副标题 | 管理员可改应用首页的副标题，最多 80 字符。留空使用当前语言的默认文案。 |

部署参数见[配置索引](/help/configuration-reference/)，网关与后端行为见[部署与配置](/help/configuration/)。
