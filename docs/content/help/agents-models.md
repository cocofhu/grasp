## 添加账号 {#credentials}

在「设置 → 凭据」添加工具平台授权或 API 账号。部分工具通过平台登录，有兼容协议的工具也可连接模型服务。在选择编码工具后查看表单提供的方式。

| 项目 | 填什么 | 作用 |
| --- | --- | --- |
| API 账号名称 | 能区分服务和环境的名称 | 在选择器中识别要用的账号。 |
| API Key / Token | 服务商签发的密钥 | 用于上游鉴权。 |
| API Base URL | 服务商的 API 基址 | 决定模型请求发送到哪里。 |
| 协议与鉴权方式 | 服务商支持的协议和密钥传递方式 | 决定可选编码工具及请求格式。按服务商要求填写自定义请求头。 |
| 模型 ID | 服务商的完整模型标识 | 用于调用模型。目录加载失败时可重试或手动填写。 |

请在凭据表单保存密钥。Agent 配置只绑定凭据或模型组的引用。工具授权过期时，在凭据页更新原账号，让仍有效的引用继续使用。

## 保存模型组 {#model-groups}

从「设置 → 凭据 → 模型组」新建。模型组把**编码工具、账号、模型和推理配置**保存成一条可复用的配置。

| 项目 | 效果 |
| --- | --- |
| 模型组名称 | 在选择器和执行记录中区分组。同名模型可通过组和工具识别。 |
| 编码工具 | 决定沙箱中启动哪个 Agent CLI。保存后需要换工具时，新建一组。 |
| 模型来源 | 选择工具平台授权或兼容的 API 账号，决定调用走哪条连接。 |
| 主模型 | 默认采用的模型。适用的工具允许使用工具默认模型。 |
| 辅助模型 | 配置该工具提供的辅助角色，或把额外的模型加入可选范围。实际支持的角色随编码工具变化。 |
| 推理参数 | 按工具和模型提供的选项设置。模型组的参数与选择一起生效。 |

## 绑定到智能体 {#binding}

打开「设置 → 智能体」，在 Agent 的模型设置中选择以下方式。默认配置位于智能体列表顶部。

- **继承默认配置**会使用默认配置绑定的模型组和默认组。
- **选择模型组**可以指定一个集合，也可以选择全部活跃组。多个组中需选出默认组。工作流自动执行时采用默认组的主模型。
- **停用和删除**会让引用该组的选择失效。打开受影响的 Agent，重新选择可用组后再运行。

模型组保存后，同一浏览器的其他标签页会更新可选项。会话中切换组从下一轮生效。要核对实际执行结果，在回复旁查看运行信息，其中记录该轮的工具、模型、推理强度和用量。
