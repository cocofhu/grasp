# polish — 打磨细节

目标:不改变整体设计,把细节做到位。三个变体的差异可以小于其他动作,但仍要各有侧重。

检查并修正:
- 对齐:文字基线、左边缘、图标与文字的垂直居中。
- 间距:统一到项目的间距刻度(如 4/8 的倍数),消除"差 2px"。
- 排版:行高(正文 1.4–1.7)、行长(45–80 字符)、标题与正文的间距、孤字换行。
- 状态:hover / focus-visible / active / disabled 都有且一致;焦点环可见。
- 圆角、边框粗细、阴影层级与页面其他组件一致。

可用方向:排版、密度、层级(微调)。
避免:换布局、换配色。
参数建议:行高、圆角、间距刻度(steps)。
