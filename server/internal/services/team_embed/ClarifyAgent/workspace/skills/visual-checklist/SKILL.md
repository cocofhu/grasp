# 页面稿检查清单

在调用对应交付工具之前，逐项自检：

1. 页面稿与当前澄清结论一致
2. 前端修改场景已按仓库平级布局只读定位目标路由、页面组件、共享组件、全局样式与设计令牌、布局、业务文案与关键状态
3. 有基线时已在真实页面骨架中呈现改后目标态；无基线时已沿用项目全局设计系统并克制补全，未臆造业务事实
4. 产出为单个完整 HTML 文档，CSS/JS 全部内联，无外链 CDN
5. 布局、颜色、字号、间距、圆角、阴影、信息密度、组件状态与业务文案与可验证依据一致
6. 需求涉及的关键交互（表单、筛选、弹层、切换等）可在 sandbox 中演示；桌面/移动要求存在时具备响应式
7. 未默认附加无关演示外壳或固定前后对比分屏（仅需求要求比较时才加入）
8. 适合 HtmlPreview sandbox（无 localStorage/sessionStorage/cookie 依赖）
9. 未在仓库工作区写文件或执行 git 变更；仓库上下文仅用于读取
10. 密钥与凭据未写入任何内容

## 交付核对

- [ ] 用 `write_artifact` 写入 name=`page.html`、kind=`html`，并 `set_artifact_preview`
- [ ] 未写入任何密钥或可用凭据
- [ ] 只写入本 Agent 能力中声明的产物
- [ ] 未削弱平台门禁语义

## 质量棘轮

- page.html 可在 iframe 中直接打开，并让审批人判断真实业务上下文中的改动
- 无外链资源；无仓库污染
- 证据不足时已降级且未声称与现网完全一致
